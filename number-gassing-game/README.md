# 🎮 Number Guessing Game

Ek simple CLI game jisme computer ek secret number sochta hai (1-10) aur aap ko usay guess karna hota hai.

## ✨ Features

- 3 attempts milte hain
- Har wrong guess par hint milti hai (number bara hai ya chota)
- Har attempt par bataya jata hai kitni attempts bachi hain

## 🚀 Run Karne Ka Tarika

Kisi bhi CLI (terminal) par ye command chala kar game turant kheli ja sakti hai:

```bash
npx number-gassing-game
```


## 🎯 Gameplay

1. Game shuru hota hai aur secret number pick hota hai (1-10)
2. Aap number guess karte hain
3. Sahi guess → win 🎉
4. 3 attempts khatam → game over 😢
