A simple command line app that counts the words in a sentence you type.

## Features

- Takes any sentence as input
- Counts words correctly (handles extra spaces, tabs and newlines)
- Clean, readable output


## How to Run

Compile the TypeScript file, then run it:

```bash
npx tsc index.ts
node index.js
```

## Run from Any Command Prompt

Once published to npm, you can run this project from any command prompt without installing it:

```bash
npx asma-678-word-counter-cli-project
```

## Example

```
? Enter a sentence to count words: hello   world, this is a test
Total words: 6
``
